# TAISELY — نسخه فرانت‌اند نهایی

این پروژه یک سایت استاتیک چندصفحه‌ای و آماده آپلود روی GitHub و Vercel است.

## امکانات فعال
- رابط کاربری فارسی و راست‌چین
- Header مشترک در تمام صفحات
- منوی همبرگری واقعی در موبایل
- حالت شب/روز با ذخیره در localStorage
- آیکن‌های Font Awesome با کلاس‌های `fas fa-*`
- Home / Blog / Article / Products / Product / Search / Cart / Account / About / Contact / Newsletter
- جست‌وجوی وبلاگ و جست‌وجوی جهانی
- فیلتر دسته‌بندی و نوع محتوا
- افزودن محصول به سبد و تغییر تعداد
- ذخیره سبد، تم، مقالات ذخیره‌شده، پسندها و دیدگاه‌ها در localStorage
- طراحی Responsive برای دسکتاپ، تبلت و موبایل
- بدون نیاز به build و بدون framework خارجی

## اجرا
فایل `index.html` را می‌توان مستقیماً در مرورگر باز کرد، اما برای بهترین تجربه، پروژه را روی GitHub و سپس Vercel قرار بده.

## Backend
