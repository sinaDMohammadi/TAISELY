# TAISELY Website

یک سایت استاتیک چندصفحه‌ای برای TAISELY، آماده برای Vercel.

## صفحات
- Home
- About
- Blog
- Products
- Contact

## اجرا
فایل `index.html` را باز کن. برای انتشار، کل پوشه را در GitHub قرار بده و در Vercel گزینه Import Project را بزن.

## نکته
متن‌های وبلاگ، محصولات و ایمیل در این نسخه نمونه هستند و باید با محتوای واقعی TAISELY جایگزین شوند.
