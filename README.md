# TAISELY — Single Page Blog

نسخه ساده و تک‌صفحه‌ای وبلاگ TAISELY.

## ساختار

- `index.html` — ساختار اصلی صفحه
- `style.css` — طراحی و حالت شب/روز
- `script.js` — مطالب، مرتب‌سازی و صفحه‌بندی
- `logo.png` — لوگوی ارائه‌شده
- `README.md` — راهنما

## اضافه‌کردن مطلب

فقط فایل `script.js` را باز کنید و داخل آرایه `posts` یک آبجکت جدید اضافه کنید:

```js
{
  title: "عنوان مطلب",
  excerpt: "خلاصه کوتاه مطلب",
  category: "فناوری",
  date: "2026-09-27",
  icon: "fa-microchip",
  url: "#"
}
```

هر صفحه ۹ مطلب نمایش می‌دهد. مرتب‌سازی فقط «جدیدترین» و «قدیمی‌ترین» است.

## انتشار

این پروژه بدون بک‌اند کار می‌کند و برای GitHub Pages مناسب است.
برای انتشار کافی است همین فایل‌ها را در repository قرار دهید و GitHub Pages را فعال کنید.

## نکته

برای تبدیل هر کارت به مقاله واقعی، `url` همان کارت را به صفحه مقاله موردنظر تغییر دهید.
